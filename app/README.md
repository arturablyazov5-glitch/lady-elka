# Lady Elka — управление каталогом

Локальный кабинет: http://localhost:4180/app

```sh
npm run start:app
# разработка с перезапуском сервера
npm run dev:app
# проверка импорта, CSV и действующих загрузчиков Taptop
npm run test:app
```

Нужен Node.js 22.13+ и `.env` в корне проекта. Для конвертации фотографий используется npm-пакет `sharp`.

## Что можно делать

- Найти товар по названию или артикулу, отфильтровать ёлки, туи, декор и скрытые товары.
- Редактировать название, типы товара, высоты, базовые цены, размеры, ветки и описание.
- В отдельной вкладке «Настройки» менять общую скидку сайта, процент сезонной корректировки цен и справочник типов.
- Итоговая цена на сайте и цена без скидки рассчитываются автоматически; ручного ввода для них нет.
- Добавлять и дублировать варианты, скрывать отдельные варианты или весь товар.
- Загружать фотографии с компьютера (JPG, PNG, WebP до 8 МБ) в Supabase Storage: сервер автоматически конвертирует их в WebP с качеством 80%; выбирать обложку и менять порядок перетаскиванием или кнопками; добавлять существующие ссылки.
- Применять описание и фотографии сразу к вариантам одной комплектации.
- Добавлять товары с новым артикулом. Артикул существующего товара заблокирован, чтобы не нарушить соответствие CMS Taptop.
- Дублировать товар из его карточки: копия открывается с тем же названием, типами и размерами — остаётся вписать новый артикул.
- Удалять товар из карточки (с подтверждением). Карточка в CMS Taptop с этим артикулом не удаляется — её нужно убрать со страницы вручную, иначе она останется без цен и фото.
- Скопировать постоянные CSV-ссылки на странице «Подключение сайта».
- В разделе «Промокоды» вести промокоды: скидка в рублях или в процентах, подарок-сумка, переключатель «работает / выключен», комментарий для себя, счётчик оплаченных заказов, дублирование и удаление.

Сохранение карточки атомарное: все её варианты записываются одним запросом. Номер версии защищает от перезаписи изменений из другого окна. При конфликте карточка остаётся открытой с ошибкой, несохранённые данные не исчезают.

Цена на сайте считается от базовой цены и сезонной корректировки: `round(base_price × (1 + adjustment_pct / 100))`. Цена без скидки считается от неё и общей скидки: `ceil(site_price / (1 - discount_pct / 100))`; при скидке 0% она равна 0. В текущих настройках скидка сайта — 30%, корректировка — 0%. Исходная цена из файла сохраняется отдельно. Действующий скрипт декора использует только итоговую цену.

## Данные

Используется существующий Supabase Lady Elka (`mgnotvaahftrbifqtahf`). Таблица `le_catalog_products` содержит JSON карточки, номер версии и дату обновления; платежные данные не затрагиваются. RLS включён, роли `anon` и `authenticated` не имеют доступа к таблице. Сервер обращается к ней через service-role, ключ в браузер не передаётся.

Миграция: `supabase/migrations/20260912000000_catalog_service.sql`. Применена через Supabase Management API отдельно от старых платёжных миграций. При подготовке будущих миграций учитывайте это: история CLI не обновлялась.

Публичный бакет фотографий: `le-catalog-images`, лимит 8 МБ, MIME-типы JPEG/PNG/WebP. Запись только через сервер. Файл публикуется при загрузке, привязка к товару — при сохранении карточки. Отмена карточки или удаление ссылки не удаляет загруженный файл из бакета: это предотвращает поломку фотографий, которые могут использоваться другими вариантами.

Первичный импорт: **40 товаров, 242 варианта** (35 ёлок/туй и 5 товаров декора). Пустые строки, второй заголовок и разделители пропущены. Скрытые варианты сохранены. Снимки источников и отчёт — `app/data/`. Повторный `node app/scripts/import.mjs` прекращает работу, если каталог уже заполнен.

## Промокоды

Раздел заменяет лист Google Таблицы `gid=301234033`. Таблица `le_promo_codes`, миграция `supabase/migrations/20260913100000_promo_codes.sql` (применена через Management API). Правила, общие для сервера и браузера, — `app/public/js/promo-model.js`; экспорт и статистика — `app/server/promos.mjs`.

В CSV попадают **только включённые** промокоды: выключенный код в фид не выгружается, поэтому на сайте он сразу перестаёт срабатывать — менять скрипт Taptop для этого не нужно.

Ограничения повторяют возможности действующего скрипта сайта, поэтому в интерфейсе нет настроек, которые сайт не умеет:

- скидка либо в рублях, либо в процентах — при двух заполненных полях сайт учитывает только рубли, поэтому сервер это запрещает;
- из подарков скрипт распознаёт только сумку для хранения (`/сумк/i`), поэтому это переключатель, а не свободный текст;
- промокод не применяется к заказам, состоящим только из декора;
- срок действия, минимальная сумма заказа и лимит применений скриптом сайта не поддерживаются, поэтому их нет и в сервисе: промокод либо работает, либо выключен.

Код уникален без учёта регистра и «ё» (unique-индекс по `lower(translate(code,'ёЁ','ее'))`) — так же, как сравнивает сайт. Счётчик «оплачено заказов» считается из `payment_orders`: скрипт сайта пишет код в описание заказа как `| Промо: КОД`. Если статистика недоступна, раздел работает без неё.

Перенос существующих промокодов из таблицы:

```sh
node app/scripts/import-promos.mjs           # предпросмотр
node app/scripts/import-promos.mjs --apply   # записать
```

Скрипт пропускает пустые строки, строку-подсказку листа и уже существующие коды; повторный запуск ничего не дублирует. Перенесено 20 промокодов.

## Ссылки для Taptop

- `http://localhost:4180/feeds/trees.csv`
- `http://localhost:4180/feeds/decor.csv`
- `http://localhost:4180/feeds/promos.csv`

Также работает форма Google Sheets: `/pub?gid=0&single=true&output=csv`, `/pub?gid=500105078&single=true&output=csv` и `/pub?gid=301234033&single=true&output=csv`.

Ответы доступны без авторизации, с `Access-Control-Allow-Origin: *` и `Cache-Control: no-store`. CSV сохраняет колонки, ID, разделитель фотографий ` | `, флаг TRUE/FALSE и порядок вариантов внутри товара. Скрытые варианты передаются с FALSE и исключаются существующим скриптом. Публичный CSV содержит только поля каталога, без исходной цены и служебных метаданных.

Текущие `src/catalog/config.js` и опубликованный Taptop пока используют Google Sheets. После домена нужно заменить `SHEET_CSV_URL`, `DECOR_SHEET_CSV_URL` и `PROMO_SHEET_CSV_URL`, собрать `npm run build`, загрузить скрипт в Taptop и опубликовать. Можно откатиться к прежним адресам. Адрес базы промокодов раньше был вписан внутри скрипта промокодов — теперь все три ссылки лежат рядом в `config.js`.

CSV не создаёт карточки в CMS: для нового товара требуется карточка Taptop с соответствующим ID. Уже существующие карточки автоматически читают изменения цен и вариантов.

## Размещение на домене

В `.env` нужны `SUPABASE_PROJECT_REF` и `SUPABASE_SERVICE_ROLE_KEY` (уже настроены локально). Для публичного запуска дополнительно:

```ini
HOST=0.0.0.0
PORT=4180
PUBLIC_ORIGIN=https://catalog.example.ru
CATALOG_ADMIN_PASSWORD=задайте_свой_длинный_пароль
```

Публичный сервер отказывается стартовать без пароля. Кабинет требует входа, публичные CSV доступны отдельно. Сессии HttpOnly/SameSite, срок 24 часа; после перезапуска требуется повторный вход. За прокси нужно сохранить Host из PUBLIC_ORIGIN. Перед публичным использованием установить HTTPS. Домен и размещение пока не выполнены.

## Дизайн

`app/public/css/styles.css` и `app/public/js/icons.js` изначально скопированы из app проекта `ПочинимВсе!/avito-ads-generator`. `icons.js` — без изменений. `styles.css` был обрезан до правил, которые реально используются в разметке Lady Elka (89 КБ → ~10 КБ; проверено CSS-покрытием headless-браузера по всем страницам, диалогам и вьюпортам, плюс визуальным сравнением скриншотов до/после) — при обновлении дизайна из исходного проекта его нужно будет сверять заново, автоматической синхронизации больше нет. Разметка повторяет `neo-top-nav → dashboard-shell → sidebar + workspace`; используются исходные шрифты, цвета, кнопки, табы и мобильная навигация. Дополнительные стили карточек и редактора находятся в `catalog-app.css`. Лендинг не использован.

## Проверено

- Оригинальные `loadDict()` / `loadDecorDict()` получают идентичные словари из исходных CSV и экспорта сервиса.
- На живых локальных CSV загрузчики видят 31 активный товар ёлок/туй и 5 товаров декора.
- Изменение цены в браузере записывается в Supabase, переживает перезагрузку и появляется в CSV; тестовое изменение отменено, все исходные данные сверены.
- Устаревшая версия карточки отклоняется с 409; запись без защитного заголовка отклоняется с 403; анонимный прямой доступ к таблице закрыт.
- Загрузка и публичное чтение фото в Supabase Storage проверены; тестовый файл удалён.
- CSV промокодов читается разбором действующего скрипта сайта: колонки, рубли, проценты и подарок распознаются. Выключенный код в фид не попадает.
- Проверены на живом сервере: создание, изменение, переключатель, дублирующий код (409), устаревшая версия (409), удаление, запрос без `X-Catalog-Request` (403). Тестовый промокод удалён, осталось 20 перенесённых.
