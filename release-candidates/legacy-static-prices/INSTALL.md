# Статические цены старого сайта

Снапшот от 08.10.2026: 248 вариантов ёлок/туй, 9 позиций декора, 10 промокодов. CSV встроены в JS. Запросы трёх CSV заменены локальными ответами; остальной код опубликованного catalog.js сохранён. Цены и наличие зафиксированы на дату снапшота.

1. Загрузить catalog-snapshot-20261008.js в ресурсы старого проекта Lady Elka в Taptop.
2. В существующем подключении заменить /f/catalog.js?v=11 на URL загруженного файла (обычно /f/catalog-snapshot-20261008.js; взять фактический URL из ресурсов). Сохранить остальные атрибуты script. Заменить подключение, не добавлять второй скрипт.
3. Проверить подключение на главной, каталогах, страницах товаров и декора; опубликовать нужные страницы.
4. В приватном окне проверить цены, выбор высоты/категории, декор, корзину и промокод. Не отправлять тестовый платёж.

Новое имя обходит годовой кеш старого JS. Отдельно CSV загружать не нужно. Фотографии и оплата всё ещё могут обращаться к Supabase; этот комплект отключает только получение цен/наличия/промокодов из CSV.

Откат: загрузить catalog-rollback.js и заменить подключение на его фактический новый URL. Не возвращать уже закешированный URL.
